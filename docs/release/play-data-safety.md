## 2. 데이터 유형별 답변

### 위치정보 (Location)

| 항목 | 답변 |
|---|---|
| 수집 여부 | **수집 안 함으로 신고 권장** |
| 근거 | 퀘스트 위치 인증은 GPS 좌표를 하버사인 거리 계산까지 전부 단말기 안에서 수행하고, 어떤 서버로도 좌표를 전송하지 않는다 (`geolocator` 결과값이 dio 요청 payload에 실리지 않음 — 코드 리뷰로 확인된 불변식). Play의 "수집" 정의는 기기 밖으로의 전송을 기준으로 한다. |
| 불변식 근거(2026-08-15 재확인) | ① 클라이언트에 좌표를 요청 body에 싣는 코드 경로가 없다. ② 서버 `_judge_gps_on_device()`는 `gps` 미션에 좌표가 오면 무시가 아니라 **거절**한다(KAN-77) — 클라이언트가 몰래 보내기 시작하면 조용히 통과하지 않고 드러난다. |
| ⚠️ 잔여 위험 | `QuestVerifyRequest` 스키마에는 `lat`·`lng` 필드가 남아 있고 `gps_photo` 미션 경로(`_judge_gps`)는 좌표를 실제로 사용한다. 현재 `gps_photo` 퀘스트는 **0건**이라 동작하지 않지만, 이 유형을 도입하는 순간 위치 수집이 시작되므로 그때 이 신고를 반드시 재검토해야 한다. |
| ⚠️ 확인 필요 | Play가 `ACCESS_FINE_LOCATION`/`ACCESS_COARSE_LOCATION` 권한 자체만으로 위치 데이터 유형 신고를 요구하는지는 리뷰 시점에 달라질 수 있음. 리뷰에서 문제 제기되면 위 근거(단말 내 처리, 좌표 미전송)를 소명 자료로 제시. |

### 사진/동영상 (Photos and videos)

| 항목 | 답변 |
|---|---|
| 수집 여부 | **수집함** |
| 세부 목적 1 — 프로필 사진 | 앱 기능(계정 관리). 저장됨(GCS/로컬 업로드 스토리지). 사용자가 언제든 교체·삭제 가능 (`backend/app/uploads/`, `auth/service.py`) |
| 세부 목적 2 — 퀘스트 인증 사진 | 앱 기능. **저장됨**(GCS/로컬 업로드 스토리지). 인증 사진은 `POST /uploads/photo`로 먼저 업로드돼 `uploaded_photos`에 소유권이 기록되고, 서버가 그 저장본을 읽어 AI 판정한다(`quests/verification.py`의 `_judge_photo` → `storage.load`). 판정 후 삭제하지 않는다 |
| 세부 목적 3 — 완료 기록 | 완료한 퀘스트의 `photo_url`이 타임라인에 남는다 (`quests/service.py`) |
| 보관·삭제 | 현재 인증 사진에는 사용자 주도 삭제 경로가 없다(프로필 이미지와 달리). 보관 기간 정책과 삭제 수단을 신고 전에 확정해야 한다 |
| 필수 여부 | 선택 (사진 인증을 쓸 때만 카메라 권한 요청, 앱 자체 이용엔 불필요) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 가능 | 예 (회원탈퇴 시 전체 삭제, 프로필 사진은 개별 삭제 가능) |
| 제3자 처리 | Google Gemini API로 인증 사진이 전송되어 AI 판정에 쓰임 — **서비스 제공자로서의 처리**로 분류 권장(직접적 제3자 공유가 아님). 이미지 자체는 Gemini 판정 후 어느 쪽에도 저장되지 않음 |

## 4. 공통 답변

- 모든 데이터는 전송 중 암호화됨 (HTTPS, KAN-64) — **예**
- 사용자가 데이터 삭제를 요청할 수 있음 — **예** (앱 내 회원탈퇴, [withdrawal_pending_screen.dart](../../frontend/lib/features/profile/withdrawal_pending_screen.dart))
- 데이터가 광고 목적으로 쓰이는가 — **아니오** (광고 SDK 없음)
- 독립적 보안 검토를 받았는가 — **아니오** (해당 없으면 체크 안 함)

# 출시 차단 조건 — 법적 동의·사진 처리

다음이 완료되기 전에는 Play 공개 출시를 진행하지 않는다.

- 개인정보처리방침의 운영자 연락처, 수탁자·처리 국가·국외 이전 근거를 실제 계약·설정과
  대조해 확정한다. 현재 앱 문서는 이 정보가 확정 전임을 명시하므로 출시용 최종본이 아니다.
- GCS 버킷의 공개 읽기를 끄고, 영구 공개 URL 대신 인증된 단기 URL/서명 URL 발급 경로를
  배포·검증한다.
- 업로드 이미지의 EXIF 등 메타데이터 제거와 탈퇴 후 삭제 실패 재시도 작업을 운영 환경에서
  검증한다.
- `PRELAUNCH_CONSENT_MIGRATION_CONFIRMED=true`를 설정하기 전에 모든 기존 계정이 외부
  사용자가 아닌 출시 전 테스트 계정임을 운영자가 기록으로 확인한다.
