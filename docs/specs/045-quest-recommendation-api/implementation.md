## 구현된 항목

- KAN-55의 인증·도메인 스냅샷·여정·퀘스트 완료 서버 연동을 재사용한다.
- `GET /quests/recommended`는 `users.dna`를 기본 카테고리로 사용하고, `category` 쿼리가 있으면 우선한다.
- `GET /regions/unvisited`는 여정 생성 이력이 없는 지역만 DNA 일치·미완료 퀘스트 수 기준으로 반환한다.
- Flutter는 `DomainCatalog`로 서버 UUID를 기존 `slug`·`client_key`로 변환하고, 서버 상태 갱신 때 추천도 재조회한다.
