# 위치정보법 검토 — 위치 기반 퀘스트 인증 (2026-07 기준)

> **면책**: 공개 자료 기반 리서치 요약이며 법률 자문이 아니다. 최종 판단은 위치정보지원센터(KISA)·방송미디어통신위원회 질의 또는 변호사 자문으로 확정할 것.
> 기준 법령: 「위치정보의 보호 및 이용 등에 관한 법률」(법률 제21066호, 2025-10-01 시행) + 시행령(2026-02-10 시행). 2025-10-01부터 소관 기관명이 방송통신위원회 → **방송미디어통신위원회**로 변경.

## 결론 (ColorTrip의 선택)

**온디바이스 검증(B안)을 채택한다.** 단말 GPS로 거리 계산까지 전부 앱 안에서 수행하고, 서버에는 좌표를 일절 전송하지 않는다. 방통위 해설서(2022-06, p.59~60)와 KISA 위치정보지원센터가 "개인위치정보를 이용자의 단말기에서만 활용할 뿐, 사업자의 위치정보시스템으로 전송하지 않는 경우 **신고 대상에 해당하지 않는다**"고 명시하고 있다.

## 두 설계안 비교

| 항목 | A안: 좌표 서버 전송·서버 검증 | B안: 단말 내 검증 (채택) |
|---|---|---|
| 위치기반서비스사업 신고(법 제9조) | **필요** — 좌표를 수신만 해도(저장 안 해도) 대상. 미신고 영업 시 3년 이하 징역/3천만 원 이하 벌금(제40조) | **불필요** (해설서 p.59~60 명문) |
| 소상공인 특례(제9조의2) | 상시근로자 5명 미만이면 사전 신고 없이 개시 가능, **개시 후 1개월 내 간이신고** 필수. 유예 중에도 동의·약관·보호조치·파기 의무는 전부 적용 | 해당 없음 |
| 이용약관·별도 동의(제12·18·19조) | 위치기반서비스 약관 6개 항목 명시 + 별도 동의 + 앱 첫 화면 공개 | 위치정보법상 의무 없음 (OS 위치 권한 고지 + 개인정보 처리방침은 필요) |
| 좌표 즉시 파기(제23조) | 거리 판정 즉시 파기 필수(미파기 2년/2천만 원) | 서버에 좌표가 없음 |
| 부정행위 방어 | 상대적으로 강함 | GPS 스푸핑·클라이언트 변조에 취약 (MVP 수용) |

## 지켜야 할 제약 (B안 유지 조건)

1. **앱의 어떤 기능·SDK도 좌표를 서버로 보내면 안 된다.** 퀘스트 인증뿐 아니라 타임라인, 지도 채색, 분석·크래시 리포트 SDK의 위치 필드까지 포함 — 하나라도 전송하면 그 순간부터 신고 대상. (현 구현: `quest_verify_screen`의 GPS 분기는 `geolocator` 좌표를 로컬 거리 계산에만 쓰고 dio 요청에 싣지 않는다. 코드 리뷰 시 이 불변식을 확인할 것.)
2. **서버에 남는 "인증 성공" 기록**(퀘스트 X를 시각 T에 완료)은 위치정보법상 위치정보로 보지 않을 여지가 크지만(2022 개정으로 정의가 "측위된 것"으로 한정) 명시적 유권해석은 확인되지 않았다. 출시 전 위치정보지원센터(lbsc.kr) 사전 질의 권장. 어느 쪽이든 이 기록은 **개인정보보호법상 개인정보**이므로 처리방침에 반영할 것.
3. 백엔드의 기존 서버 검증 경로(`app/quests/verification.py`의 gps_photo, `QuestProgress.verified_lat/lng`)는 **FE에서 호출하지 않는다**. 서버 검증(A안)으로 전환하는 시점 = 신고(또는 소상공인 간이신고) 시점이다.

## 출시 전 체크리스트 (B안)

- [ ] API 페이로드·로그·APM에 위도/경도 필드가 없는지 검증 (좌표 비전송 불변식)
- [ ] 위치 권한: 포그라운드 전용(`WhenInUse`), 기능 사용 시점 요청, 목적 문구 구체화 (iOS 5.1.1 리젝·Play 위치 정책 대응)
- [ ] Android 12+ "대략적 위치"만 허용한 사용자를 위한 안내 UX
- [ ] 개인정보 처리방침에 인증 기록 처리 내용 반영, 스토어 데이터 보안 섹션 일치
- [ ] "인증 성공 기록"의 위치정보법 해당 여부 위치정보지원센터 사전 질의(서면 답변 확보)
- [ ] 향후 좌표 전송 기능(경로 기록 등) 추가 시 = 신고 시점임을 제품 로드맵에 명시

## A안 전환 시 해야 할 일 (참고)

소상공인확인서 발급 → 출시 후 1개월 내 전자민원센터(emsit.go.kr) 간이신고 → 위치기반서비스 이용약관(6개 명시사항) 작성·앱 내 공개 → 회원가입과 분리된 위치정보 수집·이용 별도 동의 → 좌표 판정 즉시 파기 + 확인자료 자동 기록 + 위치정보관리책임자 지정·암호화·접근통제 → 상시근로자 5명 도달 시 1개월 내 일반신고 보완.
