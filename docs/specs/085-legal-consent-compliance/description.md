# [설명] 법적 동의·개인정보 처리 정합화

## 개요

이 기능은 ColorTrip의 회원가입 동의를 공개 문서와 버전 증빙에 연결하고, 불필요한 마케팅
동의를 없애며, 미성년 가입과 사진 보관·공개 위험을 줄인다.

## 동작 방식

```text
회원가입 화면
  → 이용약관/개인정보 수집·이용 전문 열람
  → 만 14세 이상 + 필수 체크
  → 서버가 terms-v2/privacy-v2 metadata를 consent에 기록
  → 일반 서비스 이용

탈퇴
  → 프로필/인증 사진 접근 즉시 차단
  → 원본·참조·업로드 이력 삭제 작업
  → 사진 없는 집계 통계만 보존

앱 외부 삭제 요청
  → /account-deletion 공개 페이지 접속
  → 앱 내 탈퇴 또는 담당자 이메일 요청 절차 확인
  → 계정 전체 또는 일부 데이터 삭제 요청
```

## 주요 구성 요소 / 위치

| 구성 요소 | 역할 | 위치 |
|-----------|------|------|
| 법적 문서 | 이용약관·개인정보처리방침의 공개와 metadata | `backend/app/legal/` |
| 삭제 요청 페이지 | 앱·개발자 이름, 요청 방법, 삭제·보존 항목 공개 | `backend/app/legal/` |
| 동의·연령 검증 | 동의 증빙, 만 14세 이상 강제, 탈퇴 | `backend/app/auth/` |
| 사진 저장 | 메타데이터 제거, 저장·삭제, 소유권 | `backend/app/uploads/` |
| 회원가입 UI | 문서 링크·연령 제한·오류 안내 | `frontend/lib/features/onboarding/` |

## 설정 / 사용법

공개 dev 환경은 운영자 정보와 실제 사진 저장소·Gemini 처리 정보를 legal configuration으로
주입한다. 현재 사진은 GCS 버킷이 아니라 서울 리전 Compute Engine의 Docker 영속 볼륨에
저장되므로, 공개 문서에도 그 사실을 표시한다. 개인 운영자의 상세 주거 주소는 저장하거나
공개하지 않고 시·구 단위만 표시한다.

`/account-deletion`은 로그인 없이 접근할 수 있다. 앱을 사용할 수 없는 이용자는 페이지에
표시된 `rainbow.dev00@gmail.com`으로 계정 삭제를 요청하며, 같은 경로로 계정을 유지한 채
일부 데이터 삭제도 요청할 수 있다. 별도 웹 폼이나 OAuth 삭제 흐름은 만들지 않는다.

## 예시

신규 사용자는 두 필수 문서를 열람하고 체크한 뒤 가입한다. 만 14세 미만 생년월일을 제출하면
서버는 전용 오류를 반환하고 앱은 안내 후 로그인 상태를 종료한다.
