## 구현된 항목

- [x] 라우터 4브랜치·마이 항목 제거·AppShell pill 디자인·테스트
- [x] 떠 있는 탭바 가림 수정(KAN-103 후속) — 셸은 `extendBody: true`라 각 탭 화면이 하단 인셋을 직접 확보해야 한다:
  - 탭 화면의 스크롤 뷰에 **명시 padding을 주면 자동 하단 인셋이 사라지므로** `MediaQuery.paddingOf(context).bottom`(탭바 높이 포함)을 더한다 — 여행 목록·타임라인·마이.
  - 셸 안에서 띄우는 바텀시트/팝업 메뉴는 브랜치 내비게이터에 뜨면 탭바가 위에 그려지므로 **`useRootNavigator: true`** 로 띄운다 — 여행 정보 시트(`trip_info_sheet.dart`), 타임라인 월 선택, 여행 카드 "···" 메뉴.
  - 토스트(`app_toast.dart`)는 하단 인셋만큼 띄운다.
  - 여행 정보 시트·퀘스트 선택 하단 버튼은 SafeArea로 시스템 내비게이션 바(edge-to-edge)도 피한다.
