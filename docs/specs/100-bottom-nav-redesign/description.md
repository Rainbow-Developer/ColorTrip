# [설명] 하단 탭 개편

## 개요

하단 탭이 홈/여행/타임라인/마이 4개로 구성된다. 바는 화면 위에 떠 있는 라운드 형태이고, 선택된 탭은 아이콘과 라벨이 함께 담긴 pill 캡슐로 확장된다(미선택 탭은 아이콘만). 타임라인은 하단 탭으로만 진입한다.

## 동작 방식

1. `StatefulShellRoute.indexedStack`의 브랜치가 홈(`/home`)·여행(`/travel`)·타임라인(`/timeline`)·마이(`/my`) 4개다. 탭 전환 시 각 탭의 내비 상태가 보존된다.
2. 탭을 누르면 선택 pill이 약 200ms 애니메이션으로 이동·확장된다.
3. 마이 화면에는 타임라인 진입 항목이 없다(경로 단일화).

## 주요 구성 요소 / 위치

| 구성 요소 | 역할 | 위치 |
|-----------|------|------|
| AppShell | 떠 있는 4탭 pill 바 렌더링 | `frontend/lib/app/app_shell.dart` |
| 라우터 브랜치 | 4개 셸 브랜치 정의 | `frontend/lib/app/router.dart` |

## 설정 / 사용법

* 없음.

## 예시

홈에서 타임라인 탭을 누르면 pill이 타임라인 위치로 이동하며 "타임라인" 라벨이 펼쳐지고, 타임라인 화면이 상태를 유지한 채 표시된다.
