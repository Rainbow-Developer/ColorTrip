## 배경 / 목적

* 타임라인은 마이 화면에서 push로만 진입할 수 있어 발견성이 낮다 — 주요 화면인데 두 번 들어가야 한다.
* 하단 바 디자인(상단 보더 + 원형 배지)이 밋밋하다는 피드백 — 선택 상태가 더 분명하고 생동감 있는 스타일로 바꾼다.

## 목표 (Goals)

* 하단 탭을 3탭(여행/홈/마이)에서 **4탭(홈/여행/타임라인/마이)**으로 바꾸고 타임라인을 셸 브랜치로 승격한다.
* 진입 경로를 하나로 유지한다 — 마이 화면의 "타임라인 보기" 항목과 단독 `/timeline` push 라우트를 제거한다.
* 하단 바를 떠 있는 라운드 바로 바꾸고, 선택 탭은 아이콘+라벨 가로 pill로 확장되는 애니메이션(약 200ms)을 준다.

## 비목표 (Non-Goals)

* 각 탭 화면 자체의 리디자인 — 하단 바와 내비 구조만 다룬다.
* 탭 상태 보존 방식 변경 — 기존 `StatefulShellRoute.indexedStack` 유지.

## 요구사항

* 탭 순서는 홈이 첫 번째: 홈 / 여행 / 타임라인 / 마이. 앱 시작 후 첫 탭은 기존 동작을 따른다.
* 딥링크·리다이렉트(`authRedirect`)가 기존과 동일하게 동작해야 한다.
* 색상은 기존 `AppColors` 팔레트만 사용한다(새 색 추가 없음).

## 설계 개요 / 접근 방식

* `router.dart`: `/timeline` 단독 GoRoute 제거, `StatefulShellBranch(routes: [GoRoute(path: '/timeline', ...)])`를 홈·여행 다음에 추가. 기존 `DomainStateGate`는 셸이 감싸므로 중복 제거.
* `app_shell.dart`: 탭 정의를 4개로 확장, 바를 `SafeArea` 안 떠 있는 라운드 컨테이너(양옆 마진·그림자·radius)로 교체. **4탭이 균등 폭 슬롯을 갖고**(탭 전환 시 아이콘 위치가 흔들리지 않도록 고정), 선택 탭은 슬롯 안에서 pill(아이콘+라벨, 폭이 모자라면 축소)로 확장, 미선택은 아이콘만.
* `profile_screen.dart`: "타임라인 보기" 진입 항목 제거.

## 의사결정 (함께 논의 · 근거 필수)

| 결정할 항목 | 선택지 | 제안 / 근거 | 상태 |
|------|--------|------------|------|
| 타임라인 진입 경로 | 탭 + 마이 항목 유지 / 탭만 | **탭만** — 같은 화면의 진입 경로가 둘이면 상태·백스택이 갈라진다(대체 경로 금지 원칙) | 합의됨 |
| 바 스타일 | 기존 보더형 개선 / 떠 있는 pill 바 | **떠 있는 pill 바** — 선택 상태 인지가 분명하고 4탭에서도 라벨 노출이 자연스럽다(선택 탭만 라벨) | 합의됨 |
