## 구현 규모 / 단위 분할

- **규모 판단**: 단위로 나눠 구현 — 근거: 7개 통계 카테고리가 서로 독립적인 쿼리라 한 번에 다 만들면 리뷰·디버깅이 어렵다. 인프라(키 인증) → 쉬운 통계 → 어려운 통계 순으로 쪼갠다.
- **구현 단위** (순서대로):
  - [ ] 1) `open_api_keys` 테이블·마이그레이션 + 키 발급 스크립트 + `serviceKey` 인증 dependency — 완료 기준: 잘못된/누락된 키에 401, 유효한 키로 빈 통계라도 200 응답.
  - [ ] 2) 방문 인증 통계 + 월별 추이 + 인기 관광지 랭킹 + 인증 방식별 참여율 — 완료 기준: `quest_progress` 기반 4개 통계가 실제 데이터로 정확히 집계됨.
  - [ ] 3) 여행자 성향(DNA) 분포 + 여정 완주 통계 — 완료 기준: `users.dna`·`journeys` 기반 집계가 정확함.
  - [ ] 4) 공유 통계 — 완료 기준: `shares.region_id` 컬럼 추가 + 생성 시 산정 로직 반영 후 지역별 집계.
