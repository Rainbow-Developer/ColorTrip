# [컨벤션] 문서화 & 협업 도구

> **범위**: 문서·API 명세·디자인·커뮤니케이션·회의.
> **변경 시**: 이 문서를 단일 출처로 갱신합니다 ([AGENT_GUIDE 문서 동기화](../AGENT_GUIDE.md#문서-동기화-필수) 참고).

## 결정 사항

| 항목 | 결정 | 비고 |
|------|------|------|
| 메인 문서 도구 | FigJam | |
| API 명세 관리 | Swagger 자동 생성 + Notion 링크(수동 업데이트) | |
| 디자인 / 와이어프레임 | Figma | |
| 디자인 시스템 | 그때그때 (정형화 안 함) | |
| 커뮤니케이션 | Slack | |
| 회의 주기 | 매주 목요일 21–23시 스크럼 | |

## 규칙 / 적용

- API 명세는 Swagger가 자동 출처이며, Notion은 수동으로 링크를 업데이트합니다.
- 코드 저장소 내 문서 체계는 `docs/`(AGENT_GUIDE·conventions·specs)를 사용합니다.
