# [컨벤션] 앱 출시 & 스토어

> **범위**: 출시 플랫폼·빌드 도구·심사 버퍼·베타 배포·스토어 계정
> **변경 시**: 이 문서를 단일 출처로 갱신합니다 ([AGENT_GUIDE 문서 동기화](../AGENT_GUIDE.md#문서-동기화-필수) 참고).

## 결정 사항

| 항목 | 결정 | 비고 |
|------|------|------|
| 출시 플랫폼 | Android 우선 | |
| 빌드 도구 | Codemagic (Flutter) | |
| 스토어 심사 버퍼 | 최소 1달 확보 | 서비스 완성 마감 8/21 기준 (확정) |
| 베타 배포 | Google Play 내부 테스트 | |
| 스토어 계정 준비 | 미정 | 미정 — 다음 결정 대상 |
| 앱 서명 키 주입 | `android/key.properties` (커밋 금지) | 없으면 debug 키 폴백 + 경고. 설계: [070-release-signing](../specs/070-release-signing/) |
| 디버그 키 해시 | 개발자별로 다름, 카카오에 각자 등록 | FE 컨테이너 `android-config` 볼륨으로 머신 내에서는 고정 |

## 규칙 / 적용

- Android를 우선 출시한다.
- 빌드는 Codemagic (Flutter)으로 한다.
- 베타는 Google Play 내부 테스트로 배포한다.
- 스토어 심사 버퍼는 최소 1달을 확보한다(완성 마감 8/21 기준).
- **서명 키와 비밀번호는 저장소에 커밋하지 않는다.** `android/key.properties`로 주입하고, 키스토어는 담당자가 생성·백업한다(분실 시 앱 업데이트 영구 불가).
- `key.properties`가 없으면 릴리스 빌드가 debug 키로 서명되며 경고를 출력한다. 이 산출물은 **내부 테스트 설치 전용**이고 스토어에 올릴 수 없다.
- **카카오 로그인 키 해시는 Play 앱 서명을 고려한다.** Play에 올리면 구글이 자기 키로 재서명하므로, 업로드 키가 아니라 **Play Console의 앱 서명 키 SHA-1**을 카카오에 등록해야 한다. 이걸 놓치면 로컬·직접 설치는 되는데 Play로 받은 앱만 로그인이 실패한다.
