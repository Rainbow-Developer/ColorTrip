## 규칙 / 적용

- 상태관리는 Riverpod로 일원화한다. 전역 상태와 서버 상태 모두 Riverpod를 사용한다.
- 서버 통신은 Dio로 처리한다.
- 지역 색칠은 지도 SDK가 아니라 이미지 기반으로 그려 색칠한다.
- 플랫폼 분기는 필요할 때만 하고, UI는 각 플랫폼의 네이티브 가이드를 존중한다.
