## 규칙 / 적용

- 개발은 프론트 그림 → 프론트 코드 → 백엔드 코드 → 완성 순으로 진행한다.
- API 명세는 마일스톤 초반에 먼저 확정한다.
- 와이어·테이블·API 명세는 한 번에 전체를 작성한다.
- MVP는 8/21 직전까지 개발하는 것을 코드프리즈 기준으로 한다.
- 작업은 기능별 오너를 지정해 분담한다.
- 스크럼은 매주 목요일 21–23시에 진행한다.
